# JavaScript, HTML Физические демонстрации

Обновленная версия HTML, JavaScript проекта по демонстрации физических эккспериментов. 

Исходная версия проекта доступна в старом репозитории [JavaScript_Physics](https://github.com/practicalDeveloper/JavaScript_Physics)

Работающий сайт с демонстрациями доступен по ссылке https://practicaldeveloper.github.io/Physics_Demonstrations/

В нынешней версии сделаны следующие изменения:

- использование классов вместо const-объектов
- создана языковая локализация
- используется requestAnimationFrame вместо setTimeout
- создана адаптивность
- Добавлены сворачивающиеся боковые панели.
- созданы боковые, сворачивающиеся панели
- создана новая демонстрации по теме 'затухающие колебания пружин'
- создана поддержка touchscreen 
- улучшена анимация
- визуальные улучшения
